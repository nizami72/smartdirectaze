# Частые вопросы покупателей: Instagram- и WhatsApp-магазины Баку

Сборник типичных вопросов покупателей на азербайджанском и русском, как их реально пишут: коротко, часто без азербайджанских букв (`qiymet`, `catdirilma`), вперемешку с русским.

Для каждого вопроса указано, откуда AI берёт ответ:

- **Данные** — AI уже отвечает сам: из каталога товаров или вкладки «Доставка».
- **Мерчант** — ответ знает только магазин. Его нужно записать заранее, иначе AI каждый раз будет звать продавца.

## 1. Цена и наличие

| Азербайджанский | Русский | Откуда ответ |
|---|---|---|
| Qiyməti neçədir? / Neçəyədir? / Qiymət? | Сколько стоит? / Цена? | Данные |
| Var? / Bu var? / Stokda var? | Есть в наличии? | Данные |
| 38 ölçü var? / Ölçüsü var? | 38 размер есть? | Данные (если размеры в описании) |
| Başqa rəngi var? | Другой цвет есть? | Данные |
| Nə vaxt gələcək? (нет в наличии) | Когда будет в наличии? | **Мерчант** |
| Qiymət directdə (ответ на пост) | Цену в директ | Данные |

## 6. Скидки и прочее

| Азербайджанский | Русский | Откуда ответ |
|---|---|---|
| Endirim var? / Son qiymət? | Скидка есть? Последняя цена? | **Мерчант** |
| Topdan satış var? / Topdan qiymət? | Оптом продаёте? Оптовая цена? | **Мерчант** |
| İki dənə alsam endirim olar? | Если возьму два, скидка будет? | **Мерчант** |
| Hədiyyə qablaşdırması var? | Подарочная упаковка есть? | **Мерчант** |
| Mağazanız haradadır? İş saatları? | Где магазин? До скольки работаете? | Данные |
| Canlı adamla danışmaq istəyirəm | Хочу поговорить с человеком | Передача продавцу |

## Что из этого следует

- Примерно половину вопросов AI уже закрывает сам, если вкладка «Доставка» заполнена полностью.
- Вторая половина — вопросы о **политике магазина**: оригинальность, производство, размерная сетка, предоплата, рассрочка, скидки, опт, обмен, упаковка, звонок курьера. Ответы на них одинаковы для всех покупателей, мерчанту достаточно записать их один раз. Отсюда идея «базы ответов магазина».
- Рассрочка по картам Birkart и Tamkart и оплата через m10 — местная специфика, их стоит предложить мерчанту отдельными вопросами.
